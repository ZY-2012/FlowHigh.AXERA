# Models

Download the two AX650 models from HuggingFace:

```bash
wget https://huggingface.co/HY-2012/FlowHigh.AXERA/resolve/main/models/flowhigh.axmodel
wget https://huggingface.co/HY-2012/FlowHigh.AXERA/resolve/main/models/bigvgan.axmodel
```

Place them in this directory. `flowhigh.axmodel` is the U16/S8 flow velocity model; `bigvgan.axmodel` is the U16/S8 48 kHz vocoder.
